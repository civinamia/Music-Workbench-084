曲幕 Verseline · Windows 便携版

双击 Verseline.exe 启动，无需安装 Python。
此入口是原生 Windows 程序，内置运行环境位于 _internal。
支持 Windows 10 / 11 64 位。请先完整解压压缩包，再启动 EXE。
如果启动失败：双击“启动诊断.cmd”，将“启动诊断报告.txt”发给开发者。
启动日志位于 %LOCALAPPDATA%\Verseline\startup.log。
支持网易云音乐和 QQ 音乐桌面版，显示原文与歌曲提供的官方译文。
在“播放与同步 → 音乐来源”选择“自动选择 / 网易云音乐 / QQ 音乐”。
QQ 音乐需要向 Windows 提供系统媒体会话（SMTC），用于读取曲目、进度与暂停状态。
如果自动模式选到了另一个播放器，可以直接指定“QQ 音乐”。
指定 QQ 音乐后，不会再读取网易云当前歌曲。无官方译文时只显示原文。
若未检测到 QQ 音乐：请更新客户端并确认已开始播放；不提供系统媒体会话的版本暂不支持。

程序文件夹：
  Verseline.exe       程序入口，可为它创建桌面快捷方式
  config.json          你的字体、颜色、字号、时间校准等设置，修改后自动保存到这里
  color_presets.json   7 套可编辑配色；原始金色始终内置保留
  ui_assets            大肥鱼 PNG / ICO 图标和界面资源
  _internal            内置引擎、Python、Qt 与运行依赖，保持和 EXE 在同一文件夹
  docs                 第三方许可证原文与界面截图
  overlay.log          运行后自动生成的诊断日志

请移动或备份整个程序文件夹；EXE 是入口，运行还需要 _internal。
字幕配色在预览下方选择，有 8 套搭配好的颜色。
点击“恢复原配色”即可恢复暖白字＋金色落影，字体、大小、时间校准保持原值。
选中预设后仍可在右侧自定义每种颜色，界面会显示“自定义配色”。

关闭窗口后，字幕继续运行。双击 EXE 或托盘图标可重新打开设置。
退出程序请使用窗口的退出按钮或托盘右键“退出”。
配置与日志需要写入权限，建议将整个文件夹放在桌面、文档或其他普通文件夹中。
