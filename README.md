# 曲幕 Verseline · Windows 版

Windows 桌面歌词层。程序读取网易云音乐或 QQ 音乐正在播放的歌曲，把当前这一句歌词显示在桌面最上层，
全屏透明、置顶、鼠标穿透，播放时不用切回播放器。

![曲幕 Verseline](docs/preview/presets/desktop.png)

当前版本 1.3.1，免安装，解压即用。窗口、托盘和 exe 使用同一套图标 `ui_assets/verseline.ico`。

## 功能

- 跟随播放进度：换句、暂停、拖动进度都会同步，暂停时字幕隐藏。
- 两种字幕风格：散落逐字和整句滑动，运行时可切换，字体字号分别保存。
- 双语字幕：原文在上，官方译文在下。播放器没有提供译文时只显示原文，不做机器翻译。
- 8 套配色：原始金色、冷白极简、暮色紫、海盐蓝、薄荷青、樱花粉、落日杏、黑白映画。
  选中后可以逐项微调，也可以恢复为原配色。
- 不干扰操作：无边框、置顶、鼠标穿透，不抢焦点，不出现在 Alt+Tab 和任务栏中。
- 托盘常驻：关闭设置窗口后字幕继续运行，托盘菜单可以控制显示、切换风格、校准时间和退出。

## 两种风格

| 散落逐字（默认） | 整句滑动 |
| --- | --- |
| ![散落](docs/preview/verification/scatter/scatter.png) | ![整句](docs/preview/verification/line/01_line.png) |

- 散落逐字：每句歌词出现在屏幕上的随机位置，随机倾斜 ±10°，字符按 0.1 秒间隔逐个出现，
  每个字带轻微随机抖动和金色落影。默认一句一条，新句出现时替换旧句，不会叠加。
- 整句滑动：一屏一句，位置在屏幕上方约四分之一处，白到金的竖向渐变加泛光投影。
  换句时旧句向左滑出，新句从右侧滑入；长句超出屏幕时直接裁切。

切换方式：托盘右键「切换渲染风格」，或修改 `config.json` 里的 `"style"`（`scatter` / `line`），保存后自动生效。

## 快速开始

1. 下载本仓库（`Code → Download ZIP`）或用 `git clone`，完整解压到桌面、文档这类普通文件夹。
2. 双击 `Verseline.exe`。首次运行如果弹出「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
3. 打开网易云音乐或 QQ 音乐播放歌曲，字幕会自动出现。
4. 想先看效果又不想放歌，运行 `Verseline.exe --demo`。

不需要安装 Python。`_internal` 是内置运行环境，必须和 exe 放在同一个文件夹，单独复制 exe 无法运行。

程序目录用于保存配置和日志，不要放在 `Program Files` 这类受保护目录，否则会写入失败。

## 支持的播放器

| 播放器 | 读取方式 |
| --- | --- |
| 网易云音乐 3.x 桌面版 | 读取客户端本地日志 `cloudmusic.elog`，获取歌曲 ID、播放状态和进度 |
| QQ 音乐、酷狗等 | 通过 Windows 系统媒体会话（SMTC）读取曲目、进度和暂停状态 |

网易云 3.x 客户端不上报系统媒体会话，因此单独通过日志读取；按歌曲 ID 获取歌词，不会匹配到翻唱。
播放源可以设为「自动选择 / 网易云音乐 / QQ 音乐」，指定后不会切换到其他来源。

## 界面

设置窗口分为三个分类，左侧是实时预览，使用与桌面相同的渲染器，2 倍放大：

- 外观与字幕：风格、字体、字号、字重、字距、文字颜色、渐变、落影或泛光、不透明度、双语开关。
- 布局与动画：散落模式的位置、行宽、同屏句数、倾斜、抖动、逐字速度；整句模式的垂直位置、
  滑动时长与距离、泛光。
- 播放与同步：整体时间偏移、音乐来源、暂停隐藏、启动行为、诊断日志。

修改后约 0.16 秒自动写入 `config.json`，没有保存按钮。预览下方的「字幕配色」下拉框中有 8 套预设；
「恢复原配色」只还原颜色，不影响字体、字号、双语、描边和时间校准。

## 托盘菜单

| 菜单项 | 作用 |
| --- | --- |
| 打开字幕工作台 | 显示并激活设置窗口 |
| 显示 / 隐藏字幕 | 只切换字幕显示状态，不暂停音乐 |
| 切换渲染风格 | 在散落逐字与整句滑动之间切换，并写回配置 |
| 时间校准 | 字幕提前 / 延后 0.2s |
| 重新加载歌词 | 按当前歌曲重新拉取一次歌词 |
| 打开配置文件 / 打开日志 | 直接打开 `config.json` 和 `overlay.log` |
| 退出 | 结束程序 |

## 命令行参数

| 参数 | 说明 |
| --- | --- |
| `--background` | 后台启动，只留托盘，不弹设置窗口 |
| `--preview [歌曲ID]` | 不放歌，用真实歌词按 1 倍速合成时钟预览 |
| `--demo` | 示例句子循环播放，不需要播放器和网络 |
| `--snapshot 目录` | 按当前配置把预览图渲染到指定目录后退出 |
| `--dump` | 打印当前检测到的会话、选中项和歌词匹配结果 |
| `--match 标题 [歌手]` | 查询这首歌能否匹配到歌词 |
| `--config 路径` | 指定配置文件，方便同时保留几套配置 |
| `--self-check 报告` | 自检内置运行时、Qt 插件、字体和绘制，输出报告 |

## 时间校准

播放器上报的进度、音频输出延迟和实际听感之间存在几十到几百毫秒的差别。托盘右键「时间校准」提供
「字幕提前 0.2s」和「字幕延后 0.2s」，调整到听感合适为止，数值写入 `config.json` 的 `offset_sec`
（正数表示字幕更早出现）。

如果整首歌稳定地偏快或偏慢，一般是播放器上报的固定偏差，校准一次即可；只有个别句子偏移，
多半是歌词文件本身的时间轴问题。

## 常见问题

**放歌了但没有字幕**
先看界面「当前播放」区域有没有识别到歌曲。没有的话运行 `Verseline.exe --dump`，检查 `sessions`
里有没有会话、`status` 是否为 `Playing`。纯音乐、播客和无版权歌曲没有官方歌词，句数显示 0 属正常。
也可以双击 `启动诊断.cmd` 生成一份环境报告。

**字迹模糊、笔画粘连**
不要用可变字体（例如 `Noto Sans SC`）搭配超粗字重，Qt5 在这种组合下轮廓实例化会出错。
散落模式建议换成微软雅黑，整句模式使用思源黑体 Heavy 这类静态字重。

**全屏游戏中看不到字幕**
独占全屏会接管显示输出，桌面悬浮窗无法覆盖。将游戏改为「无边框窗口」或「窗口化全屏」。

**修改设置没有保存**
配置写在程序目录，放在 `Program Files` 等受保护位置会写入失败。把整个文件夹移动到桌面或文档目录。

**双击没有反应**
这是单实例程序，第二次启动会唤起已打开的窗口。如果既没有窗口也没有字幕，检查托盘图标是否存在、
进程是否已经启动。

## 目录结构

```
Verseline.exe               入口（原生启动器）
_internal/                  内置 Python / Qt / 依赖，必须与 exe 同目录
ui_assets/                  图标资源
docs/licenses/              第三方许可证原文
docs/preview/               界面截图
config.json                 个人配置（首次启动自动生成）
color_presets.json          8 套配色预设（除原始金色外的 7 套可编辑）
package-manifest.json       发行包文件清单
使用说明.txt                 简短上手说明
启动诊断.cmd / 诊断启动.ps1   启动诊断，出问题时生成报告
```

## 运行环境

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，64 位 |
| 处理器 | x64 双核及以上 |
| 内存 | 4 GB（推荐 8 GB） |
| 显示 | 1280×720 及以上，支持 100%～200% 缩放 |
| 硬盘 | 约 120 MB |
| 依赖 | 无需安装 Python 或运行库 |
| 网络 | 仅用于向播放器官方接口获取歌词 |

## 已知限制

- 只在主显示器上显示，多屏没有做选择。
- 独占全屏游戏会遮住悬浮窗。
- QQ 音乐通过系统媒体会话读取，客户端版本必须提供 SMTC；部分精简版不提供时读不到进度。
- 网易云客户端面板使用多进程 CEF 渲染，无法读取文本层，亚秒级对齐只能手动校准。
