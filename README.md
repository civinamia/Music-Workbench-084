仿084的字幕工作台 · Windows版

双击 字幕工作台.exe 启动，无需安装 Python。
在网易云音乐桌面版播放歌曲后，会自动显示原文与官方译文。

程序文件夹：
  字幕工作台.exe       程序入口，可为它创建桌面快捷方式
  config.json          你的字体、颜色、字号、时间校准等设置，修改后自动保存到这里
  color_presets.json   7 套可编辑配色；原始金色始终内置保留
  ui_assets            大肥鱼 PNG / ICO 图标和界面资源
  _internal            Python、Qt 与运行依赖，保持和 EXE 在同一文件夹
  docs                 详细说明
  overlay.log          运行后自动生成的诊断日志

请移动或备份整个程序文件夹；EXE 是入口，运行还需要 _internal。
字幕配色在预览下方选择，有 8 套搭配好的颜色。
点击“恢复原配色”即可恢复暖白字＋金色落影，字体、大小、时间校准保持原值。
选中预设后仍可在右侧自定义每种颜色，界面会显示“自定义配色”。

关闭窗口后，字幕继续运行。双击 EXE 或托盘图标可重新打开设置。
退出程序请使用窗口的退出按钮或托盘右键“退出”。
配置与日志需要写入权限，建议将整个文件夹放在桌面、文档或其他普通文件夹中。
